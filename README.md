# Kindle セール一覧 タイトル別まとめ

Amazon.co.jp の Kindle セール一覧(検索結果)を全ページ読み込み、同じ作品の巻を1枚のカードにまとめて表示するブックマークレット/ユーザースクリプトです。Amazon 非公式。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 紹介ページ。ブックマークレットのボタンは、このページを置いた場所の URL から自動で作られます |
| `kindle-grouper.js` | 本体。ブックマークレットが読み込みます |
| `kindle-grouper.user.js` | Tampermonkey などのユーザースクリプト版(本体と同じ中身+右下ボタン) |

3つは必ず同じフォルダに置いてください。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る(例: `kindle-grouper`、Public)
2. 「Add file」→「Upload files」で上の3ファイル(と README.md)をアップロードして Commit
3. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして Save
4. 数分後、`https://<ユーザー名>.github.io/kindle-grouper/` で紹介ページが開きます

## 更新するとき

`kindle-grouper.js` を差し替えるだけで、ローダー型(通常のボタン)を使っている人には1時間以内に反映されます。
ユーザースクリプト版も直す場合は、`kindle-grouper.user.js` の中身を本体に合わせ、`@version` を上げてください。

## 仕組みと制限

- 使う人のブラウザから、表示中の一覧の 1〜20 ページ目を 0.5 秒間隔で読み込みます。サーバーでは何も集めません。
- Amazon は1つの並び順につき 20 ページまでしか返さないため、大きなセールは全件を拾えません(「全並び順で読み込む」で6通りの並び順を合算して取りこぼしを減らせます)。
- シリーズは Amazon の「全N巻中第M巻: 作品名」表示でまとめ、それがない本はタイトル文字から推測します。
- Amazon がページの作りやセキュリティ設定(CSP)を変えると動かなくなる可能性があります。ローダー型が動かなくなったら、紹介ページの「全部入り」版を案内してください。

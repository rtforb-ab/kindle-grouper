# Kindle セール一覧 タイトル別まとめ

Amazon の Kindle セール一覧は、同じ作品の1巻・2巻・3巻…で画面が埋まりがちです。
このツールはセール対象を全ページ読み込み、**作品ごとに1枚のカード**にまとめて表示します。カードを押すと、そのセール内をその作品名で絞り込んだ Amazon の検索結果が開きます。

**▶ 使い方とインストール: https://rtforb-ab.github.io/kindle-grouper/**

※ Amazon 非公式のツールです。Amazon とは関係ありません。

## 使い方

### ブックマークレット(おすすめ・インストール不要)

1. [紹介ページ](https://rtforb-ab.github.io/kindle-grouper/)の「Kindleまとめ」ボタンを、ブラウザのブックマークバーにドラッグ
2. Amazon.co.jp で Kindle のセール一覧(または検索結果)を開く
3. ブックマークバーの「Kindleまとめ」を押す

スマホでの登録方法も紹介ページに載せています。

### ユーザースクリプト

Tampermonkey / Violentmonkey などを入れている方は、[kindle-grouper.user.js](https://rtforb-ab.github.io/kindle-grouper/kindle-grouper.user.js) を開くとインストールできます。Amazon の一覧ページの右下に「タイトル別にまとめる」ボタンが出ます。

## まとめ画面でできること

- 作品ごとに表紙、「セール対象 ○冊 / 全○巻」、価格帯、合計金額を表示
- 作品名での絞り込み
- 並べ替え(元の並び順 / 対象冊数が多い順 / 最安値が安い順 / 合計が安い順 / タイトル順)
- 「全並び順で読み込む」で取りこぼしを減らす(下の制限を参照)

## 制限

- Amazon は1つの並び順につき20ページ(約480冊)までしか表示しないため、大きなセールでは全件を拾えません。「全並び順で読み込む」をオンにすると、6通りの並び順で読み込んで合算します(2〜3分かかります)。
- シリーズは Amazon の「全N巻中第M巻」の表示を使ってまとめます。この表示がない本はタイトルの文字から推測するため、別々に表示されることがあります。
- 何度も続けて実行すると、Amazon が確認画面(CAPTCHA)を出して途中で止まることがあります。その場合は少し時間をおいてください。
- Amazon がページの作りを変えると動かなくなることがあります。

## プライバシーと動作のしくみ

- 動作はすべてあなたのブラウザの中で完結します。表示中の一覧ページの1〜20ページ目を、通常の閲覧と同じように0.5秒間隔で読み込み、並べ替えて表示するだけです。
- 読み込んだ内容や閲覧履歴を外部へ送信することはありません。結果はそのタブの中だけに一時保存(sessionStorage)され、タブを閉じると消えます。
- ブックマークレットは、押すたびにこのサイトから本体 [kindle-grouper.js](kindle-grouper.js) を読み込みます。コードはこのリポジトリですべて公開しています。

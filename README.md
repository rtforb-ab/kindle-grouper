# Kindle セール一覧 タイトル別まとめ

Amazon の Kindle セール一覧は、同じ作品の1巻・2巻・3巻…で画面が埋まりがちです。
このツールはセール対象を全ページ読み込み、**作品ごとに1枚のカード**にまとめて表示します。カードを押すと、そのセール内をその作品名で絞り込んだ Amazon の検索結果が開きます。

**注文履歴**のページで使うと、Kindle 本で埋もれがちな注文履歴から **Kindle 以外の買い物だけを一覧**にし、Kindle 本は作品ごとに折りたたんでまとめます。

**▶ 使い方とインストール: https://rtforb-ab.github.io/kindle-grouper/**

※ Amazon 非公式のツールです。Amazon とは関係ありません。

## 使い方

### ブックマークレット(おすすめ・インストール不要)

1. [紹介ページ](https://rtforb-ab.github.io/kindle-grouper/)の「Kindleまとめ」ボタンを、ブラウザのブックマークバーにドラッグ
2. Amazon.co.jp で Kindle のセール一覧(または検索結果)か、注文履歴を開く
3. ブックマークバーの「Kindleまとめ」を押す

開いているページの URL から、セール一覧用か注文履歴用かを自動で切り替えます。

スマホでの登録方法も紹介ページに載せています。

### コツ: 先にフィルタで絞ってからまとめる

Amazon は一覧を20ページ(約480冊)までしか表示しないため、大きなセールのままでは全件を拾えません。
まとめる前に、Amazon の一覧の左側にあるフィルタ(カテゴリ)で対象を絞っておくと、結果を全部取れるようになるのでおすすめです。

例: 「Kindleストア」→「Kindle本」→「マンガ」→「シリーズ第1巻」

「シリーズ第1巻」まで絞ると各作品の1巻だけが並ぶので、セール中の作品を一覧するのにも便利です。

### ユーザースクリプト

Tampermonkey / Violentmonkey などを入れている方は、[kindle-grouper.user.js](https://rtforb-ab.github.io/kindle-grouper/kindle-grouper.user.js) を開くとインストールできます。Amazon の一覧ページと注文履歴ページの右下に、まとめ画面を開くボタンが出ます。

## まとめ画面でできること

### セール・検索一覧

- 作品ごとに表紙、「セール対象 ○冊 / 全○巻」、価格帯、合計金額を表示
- 作品名での絞り込み
- 並べ替え(元の並び順 / 対象冊数が多い順 / 最安値が安い順 / 合計が安い順 / タイトル順)
- 「全並び順で読み込む」で取りこぼしを減らす(下の制限を参照)

### 注文履歴

- 期間(過去30日・過去3か月・年ごと・全期間)を選んで、その期間の注文を全ページ読み込み
- **Kindle 以外**: 1商品1行で、注文日・商品名・金額・注文詳細へのリンクを一覧表示
- **Kindle**: 全体を1つに折りたたみ、その中を作品ごと → 巻ごとの階層で表示(冊数・合計金額・最後に買った日)
- 商品名での絞り込み(Kindle・それ以外の両方に効きます)
- 1つの注文で複数の商品を買った場合、1点ごとの金額は分からないため「注文合計・○点」として注文全体の金額を表示します

## 制限

- Amazon は1つの並び順につき20ページ(約480冊)までしか表示しないため、大きなセールでは全件を拾えません。先にフィルタで絞るのがおすすめです(上の「コツ」を参照)。「全並び順で読み込む」をオンにすると、6通りの並び順で読み込んで合算するので、取りこぼしを減らせます(2〜3分かかります)。
- シリーズは Amazon の「全N巻中第M巻」の表示を使ってまとめます。この表示がない本(注文履歴の Kindle 本はすべて)はタイトルの文字から推測するため、別々に表示されることがあります。
- 注文履歴の読み込みは1ページ10件ずつなので、1年に500件ほど注文がある場合は1分ほどかかります。「全期間」は年数に応じてさらに時間がかかります。
- 何度も続けて実行すると、Amazon が確認画面(CAPTCHA)を出して途中で止まることがあります。その場合は少し時間をおいてください。
- Amazon がページの作りを変えると動かなくなることがあります。

## プライバシーと動作のしくみ

- 動作はすべてあなたのブラウザの中で完結します。表示中の一覧ページ(または選んだ期間の注文履歴)を、通常の閲覧と同じように0.5秒間隔で順に読み込み、並べ替えて表示するだけです。
- 注文履歴を含め、読み込んだ内容や閲覧履歴を外部へ送信することはありません。結果はそのタブの中だけに一時保存(sessionStorage)され、タブを閉じると消えます。
- ブックマークレットは、押すたびにこのサイトから本体 [kindle-grouper.js](kindle-grouper.js) を読み込みます。コードはこのリポジトリですべて公開しています。

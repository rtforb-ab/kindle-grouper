Kindle セール一覧 タイトル別まとめ

Amazon の Kindle セール一覧は、同じ作品の1巻・2巻・3巻…で画面が埋まりがちです。 このブックマークレットを押すと、セール対象を全ページ読み込み、作品ごとに1枚のカードにまとめて表示します。 カードを押すと、そのセール内をその作品名で絞り込んだ Amazon の検索結果が開きます。

パソコン:下のボタンをブックマークバーにドラッグ
Kindleまとめ ← これをブックマークバーへ。
ここでクリックしても動きません。

  1. Amazon で Kindle のセール一覧(または検索結果)を開く
  2. ブックマークバーの「Kindleまとめ」を押す
  3. 読み込みが終わると(20ページで約25秒)、作品ごとの一覧が表示されます

ブックマークバーが見えないときは、Chrome / Edge なら Ctrl+Shift+B(Mac は ⌘+Shift+B)で表示できます。

スマホで使う

スマホはドラッグできないので、ブックマークを手で作ります。

  1. 下のコードをコピーする
  2. このページをブックマークに追加し、名前を「Kindleまとめ」にする
  3. そのブックマークを編集し、URL をコピーしたコードに置き換える
  4. Amazon のセール一覧を開いたら、ブックマークから「Kindleまとめ」を選ぶ
    (Android の Chrome では、ブックマーク一覧からではなく、アドレスバーに「Kindleまとめ」と入力して候補から選ぶと動きます)

まとめ画面でできること

  • 作品ごとに表紙、「セール対象 ○冊 / 全○巻」、価格帯、合計金額を表示
  • 作品名での絞り込み、並べ替え(元の並び順 / 対象冊数 / 最安値 / 合計金額 / タイトル順)
  • 「全並び順で読み込む」で取りこぼしを減らせます(下の注意を参照。2〜3分かかります)

注意

  • Amazon 非公式のツールです。Amazon のページの作りが変わると動かなくなることがあります。
  • Amazon は1つの並び順につき20ページ(約480冊)までしか表示しないため、大きなセールでは全件を拾えません。
  • 読み込みはあなたのブラウザから普通のページ閲覧と同じように行います。何度も続けて実行すると、Amazon が確認画面を出して止まることがあります。その場合は少し時間をおいてください。
  • シリーズ情報のない本は、タイトル文字から作品を推測してまとめるので、分かれて表示されることがあります。

そのほかの使い方

サイトに依存しない「全部入り」版

上のボタンは、押すたびにこのサイトから本体を読み込みます(更新が自動で反映されます)。 こちらは本体を丸ごとブックマークに入れた版で、このサイトが止まっても使えますが、更新されたら登録し直す必要があります。

Kindleまとめ(全部入り)
Tampermonkey などのユーザースクリプトで使う

ユーザースクリプト拡張を入れている方は、kindle-grouper.user.js を開くとインストールできます。 Amazon の一覧ページの右下に「タイトル別にまとめる」ボタンが出ます。

中身を確認したい

動いているコードは kindle-grouper.js ですべてです。 Amazon の一覧ページを読み込んで並べ替えるだけで、外部への送信やデータの保存(ブラウザのタブ内の一時保存を除く)はしていません。
